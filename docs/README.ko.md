## 공식 증명사진 규정을 구조화된 데이터로 활용하기

개별 JSON 또는 통합 데이터를 읽으세요. 사진 제출 전에 발급 기관의 URL과 출처 확인 날짜를 확인하세요. 저장소의 검증 상태가 접수 승인을 보장하지는 않습니다.

### 여권·비자·시험 접수용 사진 규격

| → | |
| --- | --- |
| [통합 데이터 읽기](../dist/specs.json) | JSON / source |
| [개별 규격 보기](../specs/) | Browse |

누락된 값은 null로 유지하며 추측해서 채우지 않습니다. 이번 번역은 이용 안내이며 모든 데이터 필드의 번역은 아닙니다.
